# YAML como fonte da configuração de agrupamentos

Os agrupamentos de estratégias serão definidos em um arquivo YAML local e lidos pelo pipeline e pelo dashboard. O dashboard não editará essa configuração no MVP, evitando duas fontes de verdade e mantendo as mudanças revisáveis no controle de versão; uma interface de edição poderá ser adicionada posteriormente com gravação explícita no YAML.
