# Domain Docs

This repository uses a single-context layout.

Before exploring a domain area, read:

- `CONTEXT.md`, when present;
- relevant files under `docs/adr/`, when present.

If these files do not exist, proceed without treating their absence as an error.

Use the terminology defined in `CONTEXT.md` when it exists. Surface conflicts with existing ADRs instead of silently overriding them.
